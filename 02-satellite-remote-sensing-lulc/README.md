# Satellite Remote Sensing & Land Use/Land Cover

This section curates satellite-image acquisition, preparation, visualisation, spectral analysis, land use/land cover mapping and change-detection projects.

## Existing resources in repository root
- Landsat data acquisition
- QGIS remote sensing composites
- Raster mosaicking and clipping to an AOI
- Spectral indices (NDVI, NDWI, NDBI and NDMI)
- Kikuyu Sub-County LULC map
- Nairobi true-colour composite and NDMI output
- Coffee probability mapping using VHR imagery and QGIS

See the [main portfolio index](../README.md) for exact filenames.

## Recommended evidence for each case study
Record the sensor and acquisition date, bands, spatial resolution, preprocessing, classification or index method, training/validation data, accuracy assessment, limitations and final map outputs. Do not claim classification accuracy unless supported by an assessment.
